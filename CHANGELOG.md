# Changelog

## 1.0.4 — build 136 — 19/11/2026

- Consolidação da versão 1.0.4 como base oficial do aplicativo.
- Atualização visual com paletas refinadas, cartões arredondados e volume discreto.
- Títulos com hierarquia visual mais forte e sombra suave.
- Tela de sentimentos compactada em quatro colunas, mantendo oito avatares de corpo inteiro.
- Animações dos sentimentos preservadas e configuradas para uma reprodução por seleção, com repetição por interação.
- Calendário com marcadores quadrados arredondados.
- Preservados PIN, código dos responsáveis, Room, DataStore, diário, histórico, backup local e lembretes existentes.
- Compilação validada no GitHub Actions.
- O aviso automático um dia antes da previsão continua planejado para versão futura.

## Histórico anterior

As versões 1.0.0 a 1.0.3 representam etapas de construção, correções de mídia, identidade visual e funções locais. A versão 1.0.4 build 136 é a referência atual do portfólio.
